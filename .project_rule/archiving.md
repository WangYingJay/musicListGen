- 根据反馈收敛头像上传空间：移除输入框上方的大头像上传条，只保留“图片”展开面板里的头像上传与预览卡；图片按钮增加上传数量角标，并扩展文件选择 accept 兼容 Windows 本地图片。
- 头像和素材上传增加 Windows/Electron 文件 MIME 为空时的扩展名兜底识别，避免本地图片被误判为不可用文件。
- 重设作品库页面：从成功任务兜底重建作品列表，避免画廊内存列表为空时页面无作品；改为左侧作品浏览、右侧大图预览与详情操作的工作台布局。
- 修复生图接口成功后 App 不回显结果的问题：任务结果解析兼容 `url`、`image_url`、嵌套图片字段和 base64；图生图工作区新增最近成功结果预览与保存入口。
- 修复 Windows bat 中调用 `npm install` / `npm run dev` 后脚本被 `npm.cmd` 接管的问题：改为 `call npm ...`，避免依赖安装完成后直接结束。
- 修复 Electron 主进程在 Windows 下启动 Vite 子进程时报 `spawn EINVAL` 的问题：改为通过 `cmd.exe /d /s /c npm run frontend:dev` 启动前端服务。
- 修复 Windows 开发启动时父进程看门狗误判 npm/electron 包装进程退出，导致窗口启动后被主动关闭的问题。
- 增加 `data/startup.log` 启动异常日志，避免双击启动时错误只在黑框中一闪而过。
- 修复 Windows 启动脚本在安装后端依赖时失败的问题：`requirements.txt` 增加 UTF-8 编码声明，避免 pip 在 GBK 环境下解码中文注释报错。
- `启动-windows.bat` 启动时切换控制台到 UTF-8，减少 Windows 控制台中文提示乱码。
