- 修复任务 `61fba2b478fa47649081f2d5ee76b16d` 暴露的问题：上游 `https://harin.tokenha.cn/v1/images/edits` 可能以 HTTP 200 返回业务错误体，例如 `error.message=fetch failed`、`status=502`、`code=image_generation_failed`，后端不能只凭 HTTP 状态判断编辑接口成功。已在 `backend/app/image_service.py` 中让 `_parse_upstream_response` 识别 200 响应里的 `error` 并抛出包含状态、code、generation_id 的明确错误，避免后续误报“上游响应缺少图片数据”。
